# Changelog

## 0.1.2 - 2026-09-25

- Apply fog preferences in capital cities by using the surrounding outdoor zone (for example Thunder Bluff uses Mulgore).
- Resolve outdoor zones from micro-sized map areas and update fog when the player map changes.

## 0.1.1 - 2026-09-24

- Keep the bulk fog controls within the settings panel at smaller window sizes.
- Simplify zone checkbox labels to show only the localized zone name.

## 0.1.0 - 2026-09-24

- Initial release of per-outdoor-zone volumetric fog preferences for World of Warcraft Forever.
